# Drew Nicholas — Personal Website
## Version 6

This version keeps the preferred Version 3 hero typography, remains a one-page scrolling site, refines the About and Contact alignment, reduces the Contact type size, and introduces a stylized DN monogram in the top-left corner.

### What changed
- New top-left **DN** logo/monogram using the same serif language as the hero typography
- About and Contact sections are centered more cleanly in a shared content shell
- Contact section typography reduced for better balance
- One-page structure retained
- Gallery/lightbox behavior unchanged

### Hero
Replace `assets/images/hero.jpg` to swap the hero image. The large “Drew Nicholas” title and the DN monogram are overlays, not baked into the photo.

### Gallery photos
Add images named:
- `headshot-01.jpg`
- `headshot-02.jpg`
- ...
- `headshot-10.jpg`

Place them in `assets/images/`. Missing files show as placeholders automatically.

### Social / professional links
Update the links in the Contact section inside `index.html`:
- Instagram
- IMDb
- Actors Access
- LinkedIn

To add another one later, duplicate one of the existing `<a>` elements in the `.social-links` block and change the text + URL.


### Version 7 refinements
- The DN mark is now a tighter, overlapping monogram rather than two separate initials.
- Gallery-to-About and About-to-Contact spacing is tightened for a more deliberate one-page rhythm.
- About and Contact typography has been slightly reduced and constrained for better balance.
